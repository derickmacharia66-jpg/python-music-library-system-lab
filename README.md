# OOP - Music Library System

A Python application implementing a `Song` class that tracks song metadata, unique genres, unique artists, and aggregated counts across all instances.

## Functionality
- **Instance Attributes:** `name`, `artist`, `genre`
- **Class Metrics:** Tracks total song count, unique genres list, and unique artists list.
- **Aggregated Summaries:** Maintains `genre_count` and `artists_count` dictionaries automatically on song creation.
